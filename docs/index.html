TurboWarp NFC input

Read PaSoRi card IDs from a desktop browser.

WebUSB PaSoRi connects a Sony PaSoRi reader, reads NFC card IDm and PMm values, and can write the IDm into Temporary Variables.

connect PaSoRiwait for NFC card set runtime var nfcIdm to IDmlast NFC IDm

Blocks

connect PaSoRi

Shows the WebUSB device picker and claims the PaSoRi interface.

wait for NFC card set runtime var

Polls the reader until a card is present and stores its IDm.

last NFC IDm

Reports the most recent IDm read by this extension.

API capability

Unsandboxed extensions can read `Scratch.vm.runtime.ext_kubohiroyawebusbpasori`.

const device = await pasori.connectPasori();
const card = await device.readCardInfo();
const idm = await pasori.waitForNfcIdm({signal});

Requirements and limits

This extension is intentionally scoped to Sony PaSoRi card ID reading. WebUSB requires a secure context and user device permission. Some operating system drivers or browser protected-interface rules can prevent `claimInterface(0)` from succeeding.
