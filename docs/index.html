TurboWarp NFC input

Know which PaSoRi read which tag.

WebUSB PaSoRi connects Sony PaSoRi readers under project-local names, reads NFC card IDm and PMm values, and can write the IDm into Temporary Variables.

connect PaSoRi as leftwait on PaSoRi rightlast NFC IDm on left

Blocks

connect PaSoRi as

Shows the WebUSB device picker and assigns the selected reader to a name such as `left` or `right`.

wait for NFC card

Polls a named reader until a card is present and stores its IDm.

last NFC IDm

Reports the most recent IDm read by a named reader.

API capability

Unsandboxed extensions can read `Scratch.vm.runtime.ext_kubohiroyawebusbpasori`.

const left = await pasori.connectPasori({readerId: 'left'});
await pasori.connectPasori({readerId: 'right'});
const card = await left.readCardInfo();
const idm = await pasori.waitForNfcIdm({readerId: 'left', signal});

Requirements and limits

This extension is intentionally scoped to Sony PaSoRi card ID reading. WebUSB requires a secure context and user device permission. Some operating system drivers or browser protected-interface rules can prevent `claimInterface(0)` from succeeding.
