TurboWarp NFC input

TurboWarp WebUSB PaSoRi

Sony PaSoRiリーダーを作品内の名前で接続し、NFCカードのIDm/PMmを読み取り、IDmをTemporary Variablesへ書き込めます。

connect PaSoRi as leftwait on PaSoRi rightlast NFC IDm on left

インストール

User guide: https://kubohiroya.github.io/turbowarp-webusb-pasori/

pnpm add --save-exact @kubohiroya/turbowarp-webusb-pasori@0.2.0
https://cdn.jsdelivr.net/npm/@kubohiroya/turbowarp-webusb-pasori@0.2.0/dist/webusb-pasori.js

ブロック

connect PaSoRi as

WebUSBのデバイス選択を表示し、選択したreaderを`left`や`right`などの名前へ割り当てます。

wait for NFC card

指定readerでカードが置かれるまで読み取りを繰り返し、IDmを保存します。

last NFC IDm

指定readerで最後に読み取ったIDmを返します。

API capability

unsandboxed拡張は`Scratch.vm.runtime.ext_kubohiroyawebusbpasori`を参照できます。

const left = await pasori.connectPasori({readerId: 'left'});
await pasori.connectPasori({readerId: 'right'});
const card = await left.readCardInfo();
const idm = await pasori.waitForNfcIdm({readerId: 'left', signal});

要件と制約

この拡張はSony PaSoRiのカードID読み取りに範囲を絞っています。WebUSBには安全なコンテキスト、browser support、user gesture、device permissionが必要です。OSドライバやブラウザの保護インターフェイス制限により`claimInterface(0)`が失敗する環境があります。
